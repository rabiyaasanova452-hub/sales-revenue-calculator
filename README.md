# Sales Revenue Calculator

## Описание проекта

Python-проект для автоматизации анализа продаж магазина. Программа загружает данные из CSV-файла, проверяет их корректность и рассчитывает ключевые показатели продаж.

## Бизнес-задача

Сократить ручную работу при анализе продаж и быстро определять общую выручку и товар с наибольшей суммой продаж.

## Входные данные

Файл `sales.csv` со столбцами:

- `product` — название товара.
- `sales` — сумма продаж по товару, в тенге.

## Что делает программа

1. Загружает данные из `sales.csv` с помощью Pandas.
2. Проверяет наличие обязательных столбцов.
3. Проверяет продажи на пустые и нечисловые значения.
4. Отклоняет данные с отрицательными суммами продаж.
5. Рассчитывает общую сумму продаж.
6. Находит товар с наибольшей суммой продаж.
7. Записывает события и ошибки в `sales.log`.

## Результат на тестовых данных

- Общая сумма продаж: **665 000 тенге**.
- Товар с наибольшими продажами: **Ноутбук**.
- Сумма продаж этого товара: **250 000 тенге**.

Результаты зависят от содержимого входного файла.

## Используемые инструменты

- Python
- Pandas
- Logging
- CSV
- Обработка исключений (`try/except`)

## Как запустить проект

1. Установите Python.
2. Установите Pandas: `pip install pandas`.
3. Поместите `sales.csv` в папку проекта.
4. Запустите скрипт: `python sales_report.py`.

## Структура проекта

- `sales.csv` — исходные данные.
- `sales_report.py` — программа анализа продаж.
- `sales.log` — журнал событий и ошибок.
- `README.md` — описание проекта и инструкция по запуску.
